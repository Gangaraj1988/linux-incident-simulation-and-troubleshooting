# Linux Incident Simulation and Troubleshooting

## Overview
This repository contains multiple real-world Linux incident simulations focused on troubleshooting and root cause analysis.

## Incidents Covered

### 1. Permission Issue
Application failed due to incorrect directory permissions.

### 2. Port Misconfiguration
Service running but not accessible due to wrong port.

### 3. Disk Full
Application stopped functioning due to disk space exhaustion.

### 4. High CPU Usage
System performance impacted by a high CPU consuming process.

## Approach

For each incident:
- Identified issue through logs and system checks
- Performed L1 troubleshooting (process, logs, ports, resources)
- Conducted L2 root cause analysis
- Applied fix and verified resolution

- Linux Troubleshooting
- Log Analysis
- Process Monitoring
